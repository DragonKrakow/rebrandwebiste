# How to publish as GitHub Pages

1. Create a new public repository on GitHub (e.g., `visitmacedoniasmile-githubpage`).
2. Upload all the files: `index.html`, `style.css`, and everything in `assets/`.
3. In repository settings, go to "Pages" and select the root (`/`) of the main branch for source.
4. Your site will be live at `https://<yourusername>.github.io/<repo-name>/`
5. Update images in `assets/` as needed; replace filenames in HTML if you use different names.

Optional:
- Update the Formspree form action URL to your own form endpoint for contact form functionality.
- Customize any text, images, or styles as desired!
